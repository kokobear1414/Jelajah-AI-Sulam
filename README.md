# SULAM – Jelajahi Dunia Kecerdasan Buatan

An interactive educational website developed for the SULAM programme under CSC3600 Artificial Intelligence at Universiti Putra Malaysia (UPM).

The website introduces AI applications to 20 students from Maahad Tahfiz Teduhan Kasih through interactive learning modules and practical activities.

## Features

* Programme information and details
* Interactive AI learning modules
* Module descriptions and learning materials
* Responsive design for desktop and mobile devices

## Technologies

* HTML5
* CSS3
* JavaScript

## AI Learning Modules

1. **Tarteel** – AI-assisted Quran recitation and memorisation.
2. **ELSA Speak** – AI-powered English pronunciation practice.
3. **Teachable Machine** – Creating machine-learning models without coding.
